ICLR 2027 · project pitch · v2

Every KV cache is solving
the wrong optimization problem.

Compression methods minimize how well a key is reconstructed. Attention never reads a key — it reads an output. Change the objective and the answer is classical: reverse water-filling, with eviction and quantization as the two corners nobody thought to connect.

Abstract

what the paper says

Serving long-context LLMs is bounded by the KV cache, and every method that shrinks it — quantization or token eviction — is tuned to minimize key reconstruction error. We show this is the wrong distortion measure. Posing KV compression against attention-output error yields a rate-allocation problem whose solution is reverse water-filling: the optimal bit budget for a token is linear in the log of its attention weight, and eviction emerges as the zero-rate case of the same equation. Eviction methods and quantization methods are therefore corner solutions to one program. We characterize exactly when the interior beats both — a band of per-head logit spread around \(\tau\approx1\text{–}1.5\), where it wins by 7–13× in output error at matched bits — and show that outside that band the optimum provably degenerates to one corner or the other. We realize the interior with a nested code that is free to layer, and show a single refinement pass recovers 81–101% of the oracle allocation.

The problem

why the field is stuck

At 128k+ context the KV cache dominates memory and decode bandwidth. Two families attack it, and both are in trouble:

FamilyAllocatesHow it fails
Eviction
H2O, SnapKV		{0, 16} bitsDrops tokens a future query will need. Missing one critical key produces sharp error spikes in long-output reasoning.
Quantization
KIVI, QJL, TurboQuant		{b, b} bitsAggressive variants lose up to 20 points on AIME25 and ~30% relative on 256k retrieval, and pay 10–68% latency for dequantization. FP8 beats all of them on the Pareto frontier.

These look like unrelated failure modes. They are the same failure: both families fix the allocation a priori, then optimize a proxy objective — how faithfully a key is reproduced — that attention never actually evaluates.

Attention does not consume keys. It consumes \(o=\sum_i a_i v_i\). A key carrying 0.4 of the mass and a key carrying \(10^{-6}\) are not equally worth storing, and no reconstruction metric can tell them apart.

The move

one substitution, and the answer is classical

Swap the distortion measure. Perturb stored keys so that \(\hat s_i = s_i+\delta_i\) with \(\operatorname{Var}(\delta_i)=\sigma_{b_i}^2\), and use \(\partial o/\partial s_i=a_i(v_i-o)\):

$$\mathbb{E}\|\Delta o\|^2\;\approx\;\sum_i a_i^2\|v_i-o\|^2\,\sigma_{b_i}^2\,,\qquad \sum_i b_i\le B.$$

This is textbook reverse water-filling. Stationarity gives

$$b_i^\star=\log_2\!\big(a_i\|v_i-o\|\big)+c\,,\qquad b_i^\star=0 \ \text{ below the water level.}$$

The zero-rate case is not an analogy. Dropping a set and renormalizing costs exactly \(\sum_{i\in E}a_i^2\|o_R-v_i\|^2\), so eviction's cost constant is \(c_0=1\), derived — sitting on the same axis as every quantized tier. Eviction and quantization become commensurable for the first time.

a framing we discarded This project began with an intuitive heuristic: spend precision where the selection boundary is uncertain. The theorem says the opposite. Boundary tokens carry small \(a_i\) by construction, so \(b_i^\star\) is lowest at the cut and highest deep in the head — as far from any boundary as a token can be. The optimal allocation is monotone in attention mass, not peaked at a threshold.

Where the interior actually wins

the honest version, after a correction

Once eviction and quantization sit on one axis, the obvious claim is that the interior dominates both. It does — but only over a bounded regime, and an earlier version of this pitch got the boundary backwards. The controlling quantity is \(\tau\), the per-head spread of attention logits. Because the quantization noise is \(\sigma_b=\tau\sqrt{c_b}\) while the eviction cost is fixed at 1, \(\tau\) decides which corner the optimum drifts toward.

a claim we retracted v1 of this pitch reported that the gain grows with \(\tau\), reaching 14–70×. That number compared only against uniform bits, and used a cost clamp that prevented any tier from costing more than eviction — precisely the situation that arises once \(\tau>1\). Against the best corner the curve is non-monotonic. We report the retraction because the corrected result is the more useful one: it tells you which heads to run the method on, and a method that knows where it stops working is easier to deploy than one that claims everything.
what this leaves open, and it is a lot The evictor in that table is an oracle — it ranks tokens by true sensitivity \(a_i\|v_i-o\|\), which requires knowing the very attention weights it is trying to avoid computing. Real H2O and SnapKV select on past attention statistics and cannot see the future query. So the corrected result says the interior does not beat a clairvoyant evictor at high \(\tau\). Whether it beats a practical one is unmeasured, and is a far weaker bar. That single experiment decides whether the productive band is one third of the space or nearly all of it.

Design space

five ways to occupy the interior

A per-token allocation needs a code readable to variable depth. TurboQuant's random rotation makes rotated coordinates asymptotically Gaussian, and Gaussian sources under squared error are successively refinable (Equitz–Cover) — so a nested code meets the rate-distortion bound at every layer. The rotation that makes the quantizer near-optimal is the rotation that makes it layerable at no cost. Given that, the design axis is how the ladder gets chosen:

D1 is the pick, with D5 promoted from fallback to serious contender by the correction. Storage is fixed at 8-bit keys plus FP8 values — precisely the k8v4 budget, independently measured at BF16 parity — so memory is unchanged and the entire win is bandwidth. Layer-major storage keeps every pass a contiguous strided read plus a gather, which is what stops per-token mixed precision from dying on ragged access.

Two softer benefits matter as much in review. The worst case is bounded: outside the band the method degenerates to whichever corner is optimal there, so it stops winning before it starts losing. And it subsumes rather than competes: sparse attention is recovered as the high-\(\tau\) limit with a now-quantified validity range, converting a rival literature into a corollary — at the price of conceding the margin in that regime, which is a trade we make explicitly rather than hide.

Novel claims

each one falsifiable

  1. The objective is wrong. KV compression should minimize attention-output distortion, not key reconstruction distortion. Everything else follows from this one substitution. theory
  2. Optimal precision is logarithmic in attention mass: \(b_i^\star=\log_2(a_i\|v_i-o\|)+c\), with dynamic range 13–21 bits — so uniform bit-width is not a mild approximation to the optimum. confirmed
  3. Eviction is quantization at zero rate. \(c_0=1\) is derived, not posited; H2O and KIVI are corner solutions to one program, and each loses badly in the other's regime. confirmed
  4. The interior's advantage is a bounded regime, and the theory predicts the boundary. Because \(\sigma_b=\tau\sqrt{c_b}\) while eviction costs 1, high \(\tau\) drives the optimum to two tiers. The gain over the best corner peaks near \(\tau\approx1.25\) and vanishes by \(\tau\approx2\). revised, then confirmed
  5. Unbiased quantizers make bad indices. Selection depends on the score vector only through its ordering, so monotone bias is free and variance is not. QJL's variance penalty pushes its 1-bit tier above the cost of eviction and knocks its 2-bit tier off the convex envelope — with QJL those tiers are never optimal at any budget. It costs roughly two rungs of the ladder at every \(\tau\). This independently explains why practitioners deleted QJL from the deployed implementation. confirmed
  6. Losing rungs is what turns allocation into eviction. Because the eviction cost is fixed at 1 while tier costs scale as \(\tau^2c_b\), raising \(\tau\) strips tiers off the bottom of the convex envelope. A ladder with two rungs is an evictor — so C4's regime boundary is not an empirical accident but a consequence of the same envelope argument that condemns QJL. confirmed
  7. Norm correction is the same mistake in miniature. Measured on real keys it moves the shrinkage \(\alpha\) from 0.64 to 0.80 at 1 bit while raising residual variance 57% — trading harmless order-preserving bias for order-breaking noise. confirmed
  8. Layering is free. Random rotation places rotated keys in the successively-refinable Gaussian regime, so a nested code costs no rate over a monolithic one — the enabling result for per-token allocation. to test on real keys
  9. One cascade iteration suffices to resolve the circularity that \(b_i^\star\) depends on \(a_i\), which depends on \(b_i\). confirmed

A framework that only reorganizes known results gets scored as a survey. This one made predictions before we ran anything — and the one that failed, failed into a sharper claim than the one it replaced.

What happens next

two measurements, three days, and the project is decided

The question is no longer "is \(\tau\) large?" — it is what fraction of real heads sit inside the productive band, and how much of the band's apparent narrowness is an artifact of comparing against an evictor no real system can build.
