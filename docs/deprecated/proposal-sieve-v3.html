SIEVE: Rate Allocation for KV Caches

Token eviction and cache quantization are the same optimization problem, solved at two opposite corners. Simulation now confirms both corners are dominated, and identifies the single measurement that decides the project.

Thesis. Every KV compression method minimizes a reconstruction distortion. But attention does not consume keys; it consumes an output \(o=\sum_i a_iv_i\). Posed against output distortion, KV compression is a rate-allocation problem whose solution is reverse water-filling: the optimal budget for token \(i\) is linear in the log of its attention weight, with the zero-rate case recovering eviction exactly.

Status. The oracle allocation experiment (H1) is complete and passes: water-filling beats both corners at every budget in every regime, by 10–33× in output error at realistic sharpness. Two unplanned findings came out of it — a one-pass cascade retains 81–101% of the oracle gain, and QJL is shown to delete entire tiers from the precision ladder. The project now turns on one scalar, the per-head logit spread \(\tau\), and measuring it is the next step.

1. Results to date

All numbers below are from the oracle simulation at \(L{=}32{,}768\), \(d{=}128\), averaged over 6 logit realizations × 24 noise draws, using TurboQuant's tabulated distortion constants. Code accompanies this proposal.

1.1 The circularity is not a problem

The structural doubt about the architecture was that \(b_i^\star\) depends on \(a_i\), which depends on \(b_i\). We tested the realistic version: spend 2 bits scoring every token, estimate weights from those noisy scores, allocate the remaining budget from the estimates. It retains 81–101% of the oracle log-gain across all regimes and budgets — 92–100% in the sharp and moderate regimes. The fixed-point iteration converges in a single pass. This is the most important robustness result in the set, because it means every number in Fig 1 is reachable by a deployable algorithm rather than by an oracle.

1.2 QJL does not merely add variance — it deletes tiers

M3 was previously an argument from principle — selection needs ordering, not unbiasedness. It is now a derived quantitative result, and a sharper one: QJL's variance penalty carves a hole out of the precision ladder that per-token allocation needs to be continuous. The community's empirical deletion of QJL and the allocation theory arrive at the same conclusion from opposite directions, which is the kind of convergence a paper should be built on.

An analytic argument places real models above the break-even. For logits \(\sim\mathcal N(0,\tau^2)\) over \(L\) tokens, the top attention weight is \(\approx e^{\tau\sqrt{2\ln L}-\tau^2/2}/L\); reproducing the top-1 weights of 0.1–0.3 typical of retrieval heads requires \(\tau\approx2.5\text{–}3\), placing them in the decisive band. That is an inference from a Gaussian model, not a measurement — which is why §6 now opens with the measurement.

Where the results are weakest Diffuse heads. The gain falls to 2.4–2.7× there and stays there under correlated values (\(\rho{=}0.9\)). That regime is also where sparse attention fails outright, so the honest statement is that nothing rescues diffuse heads — allocation included. The per-head escape hatch matters more than v3 credited, and the paper should say so rather than average the regime away.

2. The allocation theorem

With \(\hat s_i=s_i+\delta_i\), \(\operatorname{Var}(\delta_i)=\tau^2c_{b_i}\), and \(\partial o/\partial s_i=a_i(v_i-o)\), the first-order output error is \(\sum_i a_i^2w_i^2\tau^2c_{b_i}\) with \(w_i=\|v_i-o\|\). Minimizing under \(\sum_ib_i\le B\) gives, for tokens above the water level,

$$\boxed{\;b_i^\star=\log_2\!\big(a_iw_i\big)+c\;}$$

and \(b_i^\star=0\) otherwise. The eviction cost constant is not a modelling choice: dropping a set \(E\) and renormalizing yields exactly \(\sum_{i\in E}a_i^2\|o_R-v_i\|^2\), so \(c_0=1\) falls out of the algebra and places eviction on the same axis as every quantized tier. Three consequences:

  • Optimal bits are linear in log attention mass, whose measured dynamic range in simulation is 13–21 bits. Uniform bit-width is not a mild approximation to this.
  • Eviction is the inactive-constraint case. H2O and SnapKV are this program with the interior forbidden; KIVI and TurboQuant are this program with the boundary forbidden. Fig 1 shows each losing badly in the other's regime.
  • The cascade is the fixed-point iteration, and §1.1 shows one iteration suffices.
Still soft The linearization is first-order and \(\sigma_0\approx0.75\tau\) is not small; cross-terms \(\mathbb{E}[\delta_i\delta_j]\) from the shared sketch are dropped; and \(c_b\) comes from TurboQuant's published table rather than from measurements on real keys. All three are cheap to quantify and belong in the paper.

3. Why the nested code is free

Per-token allocation is only useful if a token can be refined mid-step without paying for the privilege. Equitz and Cover's successive refinement result establishes that Gaussian sources under squared error are successively refinable — a nested code meets the rate-distortion bound at every layer simultaneously. TurboQuant's random rotation induces a Beta coordinate law converging to \(\mathcal N(0,1/d)\), placing rotated keys in exactly that regime. The rotation that makes the quantizer near-optimal is the rotation that makes it layerable at no cost.

The practical gap: the residual after Lloyd-Max quantization of a Gaussian is not Gaussian — it is supported within a cell, with different spread in interior and tail cells. Refinement therefore needs per-cell conditional codebooks, solved once offline, data-oblivious, and tiny. Deriving this nested codebook family is the paper's concrete algorithmic contribution, and it is now load-bearing: the finer ladder of §4 needs more refinement levels than v3 did.

4. Architecture — the per-head adaptive ladder

v3 fixed three strata at \(\{2,4,8\}\). Fig 2 shows the optimum is a staircase whose width is \(\tau/\ln2\) bits, and \(\tau\) varies across heads. The ladder is therefore calibrated per head, offline, from measured \(\tau\) — narrow for diffuse heads, wide for retrieval heads. Tiers are placed at quantiles of the head's \(\log_2(a_iw_i)\) distribution, clipped to \([0,8]\) and discretized to five reachable precisions.

STORAGE — one nested code per key, written once. 8b K + FP8 V ≡ k8v4 budget, 2.0× vs BF16.
Layer-major: all L0 bits contiguous across tokens, then L1, then L2 ...
Per-head increments; a sharp head and a diffuse head split the same 8 bits differently.

  pass 1-4 shrinking sets   read +1/+1/+2/+2  ──►  refine tokens whose b* exceeds the level
  tail     b* = 0           page centroids  ──►  low-rank correction

  o = Σ_{b*>0} â_i v_i  +  Σ_{pages P with no survivor} (mass in P) · v̄_P

  Total bytes = B·L regardless of level count: pass ℓ touches only tokens with b* ≥ ℓ.
  More levels cost kernel launches and parallelism at small subsets, not bandwidth.

Why five levels and not nine. Bandwidth is invariant to level count — the budget constraint fixes it — so the only cost of a finer ladder is launch overhead and shrinking occupancy on the last passes. Five levels capture the bulk of the measured histogram (2–5 bits holds 76% of tokens) while keeping the deepest pass over ~1% of the sequence. Level count is an ablation, not a hyperparameter to defend.

Graceful degradation is structural. If a head is diffuse and the ladder collapses toward uniform, SIEVE degrades continuously to uniform 4-bit rather than breaking — the failure mode v3 could not survive. Fig 4 quantifies the floor: even at \(\tau{=}0.5\) the method never loses to uniform, it merely stops winning.

Tail correction

Pass 0 already produced coarse weights for every token at no extra cost, so the \(b^\star{=}0\) tail can be summarized by per-page mass-weighted value centroids rather than discarded — replacing an error bound governed by value magnitude with one governed by within-page value variance. Under 1% of cache bytes at 128-token pages. Ablatable.

H1 is complete, so the gate moves to the measurement that its own sensitivity analysis identified. H0 is new, costs a day, and is now decisive for the entire project.

The headline paper experiment remains the iso-budget ablation: hold bytes read fixed, compare uniform 4-bit against the calibrated ladder, on real models. Same bandwidth, memory and kernel; the only variable is where the bits go. Fig 1 is the simulated version of that plot, and reproducing its shape on hardware is the paper's central claim.

8. The three ways this still dies

  1. \(\tau\) is small in practice. Fig 4 makes the failure mode precise rather than vague: below \(\tau\approx1\) the theorem is correct and the method is inert. One day of measurement settles it, which is why H0 runs next.
  2. Successive refinability does not survive finite \(d\) and scalar quantizers. Equitz–Cover is asymptotic and assumes optimal vector quantization; TurboQuant uses per-coordinate Lloyd-Max at \(d{=}128\), and the finer ladder now stacks four refinement boundaries instead of two. If nesting costs 20%, per-token allocation stops being free.
  3. A reviewer reads it as classical theory in a transformer costume. The defense is that the reframing predicts: it predicted the ladder width, it predicted that unbiased quantizers make poor indices, and it predicts eviction dominates only in the low-budget high-\(\tau\) corner. Two of those are confirmed in simulation. A framework that only reorganizes known results is scored as a survey; one that makes falsifiable predictions and survives them is not.
